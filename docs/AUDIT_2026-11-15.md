### Fix now
1. **Plain http is not redirected to https.** `http://loans.sharet.africa/` answers 200. Add a redirect (LiteSpeed vhost rewrite or `.htaccess`), then turn on HSTS.
2. **No security headers.** None of Strict-Transport-Security, X-Frame-Options, X-Content-Type-Options, Referrer-Policy or a Content-Security-Policy is sent. Add a small middleware (or vhost headers): HSTS, `X-Frame-Options: SAMEORIGIN`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`.
3. **Staff investment page crashed** for partner lines with a note ("foreach() argument must be of type array, string given", 6 times since 13 Nov). Fixed in `23def1d`, not yet deployed.

### Later
4. Pages take 0.7–1.0 s before the first byte. Check `php artisan optimize` runs on deploy (config/route/view cache) and OPcache is on; consider LiteSpeed page cache for the public pages.
5. Disk 76%: add a weekly clean of old `~/backups` and `releases` beyond the last 3.
6. Live PHP upload limits were 2 MB / 8 MB and `public/.user.ini` is ignored on this server; the site's limits now live in the LiteSpeed vhost (`phpIniOverride`, 2048 MB).
